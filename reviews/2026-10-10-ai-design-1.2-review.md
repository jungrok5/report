# ai-design 1.2.0 재검토

기준은 [jungrok5/ai-design 1.2.0](https://github.com/jungrok5/ai-design/tree/41a545e358ca7a87fa615746c1804661af76dbd5)의 글·UI 스킬과 공통 문서입니다. 보고서는 이슈 제목 → 현상·공통 시간축 → 원인 → 조사 과정·근거 순서를 유지합니다.

| 확인한 문제 | 반영 |
| --- | --- |
| 현상 영역의 영향·회복 기록을 원인 영역에서 그대로 반복 | 기록은 현상 영역에 보존하고 원인 영역에서 해당 위치로 연결 |
| 현상·원인·조사가 같은 좌측 제목 틀을 연속 사용 | 원인은 가로 전체를 사용하는 요약 영역으로 분리 |
| 10–21px 사이의 여러 글자 크기로 위계가 불분명 | 12·14·16·20·24px 공통 토큰과 제목 토큰 적용 |
| 조사 상세에서 본문의 관측과 근거 버튼을 반복 | 관측·판정은 본문, 가설·예측·다음 확인은 상세에 표시 |
| 인쇄본에 비어 있는 인과 그래프 제목과 내부 이동 주소 표시 | 화면 전용 그래프 영역은 숨기고 전체 인과 기록을 별도로 인쇄; 외부 URL만 주소 병기 |

동접·DB 부하·지연의 범례는 실제 수치 그래프에 필요한 항목이므로 유지합니다. 조사 단계 번호도 확인 순서를 나타내므로 유지합니다. 원인 후보·판정·수치·시각·조회 URL·보존본·검토 기록은 수정하지 않았습니다.

[검증 결과](https://github.com/jungrok5/report/actions/runs/38022600623): 내장 원문 해시, 새 스타일 규칙, Python·모델 테스트, 재생 예시·보존본 바이트 비교, 빌드, 세 보고서의 시각 탐색·근거 조회·검토·import·인쇄, 독립 HTML과 조사 엔진 HTML의 브라우저 조작을 통과했습니다. 375·768·1024·1440px의 라이트·다크 화면과 원인 본문 대비, 다크 모드에서의 인쇄 대비도 확인했습니다.

로컬 명령 실행기가 응답하지 않아 검증은 GitHub Actions의 Chromium에서 실행했습니다. 별도 에이전트의 로컬 스킬 생성 시험은 실행하지 못했습니다. 자동 검사는 실제 운영 장애의 원인 진위나 수신팀의 이해도를 증명하지 않습니다.
