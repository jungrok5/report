# 장애 보고서 화면 기준

이 화면은 장애의 현상과 원인 후보를 읽고, 조사 판정과 보존 근거를 확인하는 문서입니다. ai-design의 글·UI 기준을 적용합니다.

- 이슈 제목 → 현상·공통 시간축 → 원인 → 연속 조사 과정 → 인과관계·근거·조치 순서를 유지합니다.
- 큰 제목, 짧은 문서 정보, 구분선과 여백으로 보고서의 위계를 표현합니다. 섹션마다 같은 카드 모양을 반복하지 않습니다.
- 넓은 화면에서는 섹션 제목을 왼쪽에, 본문을 오른쪽에 둡니다. 모바일에서는 한 열로 읽습니다.
- 원인 요약은 짙은 면과 큰 본문으로 강조합니다. 유력·미확인·검증됨은 별도 상태로 표시합니다.
- 현상의 수치 추이는 한 시간축에 겹칩니다. 범례는 실제 관측 범위이며 지표별 상대 높이를 실제 크기로 비교하지 않습니다. 수치·단위·표본 시각·설명은 툴팁에 보존합니다.
- 보고서 정보와 조작 설명은 펼쳐 확인합니다. 가상 예시 표시는 항상 보입니다. 조사 단계의 관측과 판정도 항상 보입니다.
- `report-tokens.css`의 색·글꼴·모서리 토큰을 사용합니다. 라이트·다크·인쇄 모두 같은 내용으로 표시합니다.
- JSON, 근거 표본, 조회 URL, 상태와 검토 기록은 화면 변경으로 수정하지 않습니다.
