# 장애 보고서 화면 기준

이 화면은 장애의 현상과 원인 후보를 읽고, 조사 판정과 보존 근거를 확인하는 문서입니다. ai-design의 글·UI 기준을 적용합니다.

- 이슈 제목 → 현상·공통 시간축 → 원인 → 연속 조사 과정 → 인과관계·근거·조치 순서를 유지합니다.
- 큰 제목, 짧은 문서 정보, 구분선과 여백으로 보고서의 위계를 표현합니다. 섹션마다 같은 카드 모양을 반복하지 않습니다.
- 현상은 제목 아래에 본문과 넓은 시간축을 배치합니다. 원인 요약은 한 열의 문단으로 읽습니다. 조사 기록은 질문과 해당 관측·판정을 나란히 두고, 좁은 화면에서는 순서대로 읽습니다.
- 원인 요약은 중립 배경과 큰 본문으로 구분합니다. 짙은 강조 상자와 상태 배지를 반복하지 않습니다. 현재 판정의 유력·미확인·검증됨은 글자로 표시합니다.
- 현상의 수치 추이는 한 시간축에 겹칩니다. 범례는 실제 관측 범위이며 지표별 상대 높이를 실제 크기로 비교하지 않습니다. 수치·단위·표본 시각·설명은 툴팁에 보존합니다.
- 보고서 정보와 조작 설명은 펼쳐 확인합니다. 가상 예시 표시는 항상 보입니다. 조사 단계의 관측과 판정도 항상 보입니다.
- `report-tokens.css`의 색·글꼴·모서리 토큰을 사용합니다. 라이트·다크·인쇄 모두 같은 내용으로 표시합니다.
- 글자 크기는 12·14·16·20·24px 단계와 28–44px 제목 토큰을 사용합니다. 작은 화면의 보조 정보도 12px 아래로 줄이지 않습니다.
- 영향·회복 기록은 현상 영역에 표시합니다. 조사 관측과 판정은 본문에 표시하며 같은 라벨을 매 단계 반복하지 않습니다. 상세에는 가설·예측·다음 확인을 둡니다. 사건 목록은 펼쳐 선택하며 인쇄본에는 전체 기록을 표시합니다. JSON과 인쇄본의 기록은 보존합니다.
- `report-hierarchy.css`는 React와 독립 HTML이 공유하는 시각 계층입니다. 영향·회복은 정의 목록, 시간축은 관측 배경, 원인은 문단 요약, 조사 기록은 질문·근거의 두 열, 조치는 담당·기한·상태가 있는 기록으로 구분합니다.
- JSON, 근거 표본, 조회 URL, 상태와 검토 기록은 화면 변경으로 수정하지 않습니다.
